# JGAMES

Landing page de una revista independiente de videojuegos, implementada con React, TypeScript y Vite.

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

El catálogo, la búsqueda, la cesta y el formulario de suscripción son interacciones locales de demostración. Las fotografías de la referencia Stitch se cargan desde URLs de Google.
